# Web-Traffic-Analytics
# Web Traffic Analytics and User Behavior Analysis

## Project Overview
This project analyzes website traffic and user engagement using Google Analytics 4 (GA4) event data. The goal is to understand user behavior, identify engagement patterns, analyze traffic sources, and detect user drop-off points to improve website performance and engagement.

---

## Objectives
- Analyze website traffic behavior
- Identify key user engagement metrics
- Study traffic acquisition sources
- Understand device and browser usage
- Map user journey and drop-off behavior
- Generate business recommendations for improving engagement

---

## Dataset
Google Analytics 4 (GA4) Sample Dataset

The dataset contains:
- Website event activity
- User engagement events
- Traffic source information
- Device and browser data
- Promotion and product interaction events

---

## Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## Data Cleaning and Processing
The following preprocessing steps were performed:
- Filtered valid event-level records
- Removed irrelevant and empty records
- Extracted event activity information
- Prepared traffic and engagement metrics for analysis

---

## Exploratory Data Analysis

### Event Analysis
Analyzed key website events including:
- page_view
- session_start
- scroll
- user_engagement
- view_item
- select_promotion

### Traffic Source Analysis
Traffic sources analyzed:
- Google
- Direct traffic
- Referral traffic
- Other acquisition channels

### Device and Browser Analysis
Studied:
- Desktop vs Mobile traffic
- Browser usage distribution

### User Engagement Analysis
Measured:
- User engagement events
- Interaction depth
- Promotion interaction

### User Journey and Drop-Off Analysis
Mapped user flow:

session_start → page_view → scroll → user_engagement → view_item → select_promotion

This helped identify user drop-off stages and engagement decline patterns.

---

## Key Findings
- Page views were the most frequent website activity.
- Google was the primary traffic acquisition source.
- Desktop users formed the majority of website visitors.
- Chrome was the dominant browser.
- User engagement decreased as users progressed deeper into the interaction funnel.
- Promotion interaction rates were relatively low.
